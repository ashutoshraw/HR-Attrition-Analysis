# HR Employee Attrition Analysis & Prediction

## Project Status: In Progress 🔄

## Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- MySQL
- Power BI
- Machine Learning (Scikit-learn)

## Dataset
IBM HR Analytics Employee Attrition Dataset (Kaggle)
1470 employees | 35 features

## Project Phases
- Phase 1: Data Cleaning ✅
- Phase 2: EDA ✅ 
  → 11 charts created
  → Key finding: Overtime employees 3x more likely to leave
- Phase 3: Machine Learning ✅
  → Logistic Regression: 87.41% accuracy
  → AUC Score: 0.806
  → Top Predictor: Stock Option Level
- Phase 4: Power BI Dashboard ⏳
- Phase 5: Business Report ⏳

## Key Findings So Far
- 16% overall attrition rate
- Sales department highest risk
- Overtime employees 3x more likely to leave
- Stock options strongest retention factor
- Young employees (18-25) most vulnerable
